This page summarises how this website handles personal data. The [full privacy policy](/privacy/de/) is available in German and is the authoritative version. Last updated November 2026.

**Controller.** Luca Walz, [contact@lucawalz.dev](mailto:contact@lucawalz.dev).

**Server logs.** Requests to this site are logged with technical data such as time, requested page, browser and referrer, which may include the IP address. The logs serve operation and security and are deleted after 14 days. Legal basis: legitimate interest in running a secure website (Art. 6(1)(f) GDPR).

**Cloudflare.** The site is delivered through Cloudflare, Inc. (USA) as content delivery network and secure tunnel to the server, which processes the IP address and request data for that purpose. To detect malicious traffic, Cloudflare may set a strictly necessary security cookie. Legal basis: legitimate interest (Art. 6(1)(f) GDPR).

**Comments.** Comments are provided by giscus and stored in GitHub Discussions (GitHub, Inc., USA). Nothing is loaded from giscus or GitHub until a visitor clicks "Load comments"; only then is the IP address sent to giscus.app and GitHub. Writing a comment requires a GitHub account. Legal basis: consent given by that click (Art. 6(1)(a) GDPR, section 25(1) TDDDG).

**Email.** Messages to the contact address are used only to answer them and are deleted when no longer needed.

**No tracking.** This site uses no analytics, no advertising and no tracking cookies.

**Transfers to the USA.** Cloudflare and GitHub are certified under the EU-US Data Privacy Framework.

**Rights.** Visitors have the right to access, rectification, erasure, restriction of processing, data portability and objection, and may withdraw consent at any time. Requests go to the contact address above. Visitors may also lodge a complaint with a data protection authority, in particular the Landesbeauftragte fuer den Datenschutz und die Informationsfreiheit Baden-Wuerttemberg.
