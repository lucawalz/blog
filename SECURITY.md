# Security policy

This repository holds a static site: Hugo builds plain HTML that nginx serves. It has no server-side code, accounts or stored user data.

## Reporting a vulnerability

Report vulnerabilities through the repository's private vulnerability reporting form: https://github.com/lucawalz/blog/security/advisories/new

Please do not open a public issue for a vulnerability.

## Response

- Acknowledgement within 7 days.
- Coordinated disclosure within 90 days of the report.
